# Kojo

> Kojo is a construction materials management and procurement platform for
> specialty trade contractors. It connects the field, purchasing, the warehouse,
> the prefab shop, and accounting so material can be requested, sourced,
> purchased, tracked, received, and paid for in one system. Kojo has no public,
> self-service developer API: its machine-to-machine surface is a partner-gated
> Vendor Integration Portal running ANSI ASC X12 EDI and scheduled file feeds,
> plus ERP and project-management connectors.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from
apis.yml and the artifacts in this repository. Kojo does not publish its own
/llms.txt.

## APIs

Kojo publishes no OpenAPI description, no REST or GraphQL reference, and no
developer portal. `developer.usekojo.com`, `docs.usekojo.com`, and
`api.usekojo.com` do not resolve. API integration is referenced in the vendor
documentation but is arranged directly with the Kojo team and is not documented
publicly. Do not assume an endpoint exists.

- Integration contact: vendor-integrations@usekojo.com
- Enablement support: vendorsupport@usekojo.com

## Integration surface

- [Kojo Vendor Integration Portal](https://support.usekojo.com/hc/en-us/articles/35653301501331-Kojo-Vendor-Integration-Portal): Where vendors set up and enable integrations.
- [Enabling EDI and API integrations](https://support.usekojo.com/hc/en-us/articles/36704454593811-Enabling-EDI-and-API-Integrations-in-the-Kojo-Vendor-Integration-Portal): Go-live process and per-customer enablement rules.
- [What is an EDI integration](https://support.usekojo.com/hc/en-us/articles/36080820798611-What-is-an-EDI-Integration): EDI primer with a sample X12 850 envelope.
- [Vendor Integration Portal EDI Log](https://support.usekojo.com/hc/en-us/articles/35653535248915-Vendor-Integration-Portal-EDI-Log): Transaction monitoring, outcomes, and raw file download.
- [Vendor catalog and pricing integrations](https://support.usekojo.com/hc/en-us/articles/36701449152787-Vendor-Catalog-Pricing-Integrations): Catalog and price-list file feeds.
- [Inventory availability integration](https://support.usekojo.com/hc/en-us/articles/36704979506835-Inventory-Availability-Integration): Branch-level inventory feeds.
- [Customer account numbers and identifiers](https://support.usekojo.com/hc/en-us/articles/37103586982163-Adding-and-Editing-Customer-Account-Numbers-Identifiers): Binding Kojo customers to vendor ERP records.

Supported X12 transaction sets: 810 (Invoice), 840 (RFQ), 843 (Quote),
850 (Purchase Order), 855 (Purchase Order Acknowledgement).
